# Gestor de Veículos

Um sistema simples em Java para gerir veículos — ideal para registos, consultas e manutenção de dados de veículos.

## Descrição do Projeto

Este projeto permite criar, armazenar e gerir uma lista de veículos com informações como marca, modelo, ano, matrícula, proprietário, etc. Pode servir como base para aplicações de gestão de frotas ou pequena oficina, ou simplesmente como exercício em Java orientado a objetos.

## Funcionalidades

- Adicionar novos veículos  
- Remover veículos existentes  
- Listar todos os veículos  
- Pesquisar veículos por critérios (por exemplo — matrícula, marca, modelo)  
- Atualizar dados de um veículo  

## Tecnologias / Requisitos

- Java 8+ (ou versão usada no projeto)  
- Sistema de ficheiros local ou base de dados — dependendo da implementação atual (se existir persistência)  
- IDE recomendada: IntelliJ, Eclipse, VS Code + extensão Java ou outra da tua preferência
